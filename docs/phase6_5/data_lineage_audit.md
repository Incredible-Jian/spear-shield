# Phase 6.5 数据反向溯源

范围：本轮真实缓存回放，以及独立标记的异常回归。状态 **PARTIAL**：本轮回放内部记录可链接，不等于历史市场信息可知性完整。

## 反向链

`账户净值 → 当日实际成交回执 → 成交 → 目标订单 → 周线裁决/实际预置保护指令 → 各条件 TRUE/FALSE/UNKNOWN → 特征数值和口径版本 → 指数/ETF 输入快照 → 来源版本与哈希`。

`backtest/lineage.py` 为节点保存内容哈希及运行 ID。运行 ID 包含执行行情哈希、指数信号预热快照哈希、ETF ATR 预热快照哈希、数据来源版本、冻结配置和实现文件哈希。内容修改后验证失败；来源版本变动产生不同运行 ID，保留原报告。JSON 保存/读取后仍验证节点哈希。哈希保证指定内容的一致性，不能认证供应商真实性。

周线裁决保存每条规则的条件表达式、输入键、三值结果、待确认定义、是否实际发出目标。没有发出目标时不制造成交信号。日内保护指令从实际保存的回执链接，独立于普通周线信号；没有记录的旧报告不补造证据。部分成交记录实际份额和取消回执，尚未全部成交的阶段不冒充完成。

## 实际和异常测试

`tests/integration/test_phase65_audit.py`：

- 用真实缓存首次防守成交日，逐级断言三笔防守成交、来源、Z 值、指数周收盘、次交易日时间、开盘价加滑点、费用及现金/净值恒等式。
- 实际回放中核弹条件 UNKNOWN、零进攻成交、完整策略收益为 null；不得把 UNKNOWN 标为正常。
- 仅修改副本的来源版本元数据，运行 ID 改变、经济结果不变；原始报告保持不变。篡改净值节点会被拒绝。
- 用明确的合成异常测试检查部分风险成交后取消、跨周风险去重、周内缺价传播及重新预热、小仓位 P0 不被防守容差吞掉。
- B02 旧目标在 ATR 后重买为 strict xfail。它是已确认失败场景，不能计作通过，不能据此给执行链整体 PASS。

具体节点数量、链接缺口、归因残差及运行指纹见 [真实回放证据](manifests/replay_evidence.json)。完整节点、原始输入和 HTML/CSV 报告留在该文件指向的本地 `cache/phase65/final_replay_*`，不上传大数据。

## 仍未认证的部分

历史宏观发布时间使用显式的下一交易日假设，非实际历史发布档案；当前获取的前复权历史可能包含后来公司行动因素。ETF 各历史时点复权因子、完整停牌/公司行动及部分外部指标尚缺。源文件哈希匹配、交易日隔离和无合成标记不能消除这些信息时点限制。内存生命周期状态、跨入口规则差异及逐批资格亦未完成端到端持久恢复认证。
