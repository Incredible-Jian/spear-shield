# 回测工作区与计算口径

启动：`python -m spear_shield`，进入“历史回测”。使用已有本轮验收缓存可运行：

```powershell
python -m spear_shield --data-dir D:/spear-shield/cache/phase5-preview
```

选择日期/初始资金/单边手续费和滑点，选择“持有创业板ETF”“防守固定配比”或“三方案对比”。基准固定初始配置买入持有，防守三权重可自行设置且合计100%。这不是依据当前Z值计算的动态防守。运行不自动联网；缺行情请先到数据管理更新对应ETF前复权行情。

“矛与盾完整策略”目前只检查并列出阻塞原因，不计算收益。未经确认规则与缺IV/股债性价比等条件仍保持待确认/缺失，不自动豁免。

## 成交与数据

- 桌面当前使用前复权**研究单位**，不是实际ETF份额，不等于精确分红再投资收益。回溯qfq历史无法证明当时可知，不能当作正式策略无前视回测。
- 基准初始目标是开始日前预先指定的配置意图，首个区间内观测交易日开盘买入；不是假装提前知道首日收盘。一般信号在15:30之后生成，后续交易日开盘成交。
- 买入价=开盘×(1+滑点)，卖出价=开盘×(1−滑点)，费用=成交金额×手续费率。买入按等比例可用现金预算取整，残余现金保留，不使用杠杆。
- 默认交易单位1是研究参数，不能解读为交易所申报规则。引擎接口可设置交易单位；普通部分卖出向下取整，整笔清仓允许拆分零碎份额，报告记载此模型假设。
- 日历来源展示为缓存日期并集、未认证完整；不取交集掩盖缺口。某标的在其它已知交易日缺行情会阻塞。所有标的同时缺一天时，仅凭行情缓存无法发现，需要外部完整日历。
- 请求首尾日期与实际观测首尾不同时，明确标为“部分区间研究”，界面和HTML同时列出请求/实际日期，不静默把少量缓存当作覆盖整段历史。没有独立日历时，节假日边界也无法自动认证，仍保守显示此状态。
- 原始价引擎`raw_events`（Python接口）另需显式`TradingCalendar(complete=True)`与公司行动覆盖声明，不在桌面里把缺分红数据的原始价当总收益。
- `CorporateAction`采用除权前持仓、拆分前每份税后现金。除权日产生应收，派息日或之后首个观测交易日入现金；拆分调整份数，成本总额不变。分红归集入卖出加权损益，不重复计入净值。
- 停牌必须有显式记录及明确估值价，不能只把未知缺日当停牌。停牌订单顺延，可被更新目标取代；尾日未成交保留，不用收盘强制成交。

## 绩效

- 累计收益=期末权益/初始资金−1。权益包括现金、持仓收盘市值和未派发应收分红。
- 最大回撤包含初始资金高水位，因此首日成本不会消失。
- 年化区间从首日09:30到末日15:00，按365.2425天/年；不足一年不展示不稳定外推，显示“—”。
- 夏普采用日收益样本标准差ddof=1、年252日、无风险利率0。首日相对初始资金的收益含交易成本。零波动/不足样本时不可计算。
- 胜率按卖出成交的加权平均含费用、含分红损益统计，盈亏比=平均盈利/平均亏损绝对值。不是逐建仓批次配对。没有卖出时不可计算，无亏损时盈亏比/利润因子也留空，不显示无穷大。
- 对比表显示每个方案状态；不可计算不显示0。卡片/仓位图对应第一个成功方案，净值图覆盖全区间；累计成交表与CSV保留成交价/单位/费用/时间和原因。

## 报告与取消

后台计算可取消，离开页面可继续，关窗终止任务。运行最长120秒。成功后报告保存在独立数据目录`backtests/<随机运行ID>/`，与行情数据库和模拟账户分开；可导出ZIP，含JSON、HTML、资金曲线/交易/订单/信号CSV和SHA256。

JSON保留完整输入快照与输入指纹、公司行动日志、费用/滑点、日历来源、有效首末日期、所有状态及限制。研究参数请求也单独保存。报告只在全部方案计算结束后载入；被取消进程可能留下已完成但尚未载入的独立报告目录，不会改变行情或账户。

使用真实验收脚本：`python scripts/validate_phase6_real_data.py`。只使用真实行情，联网不可用则保留失败原因，不制造防守基准或正式策略收益。
