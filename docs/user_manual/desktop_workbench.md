# 桌面工作区使用说明（Phase 5）

## 启动

开发环境Python3.12.4，PySide6 6.8.1.1，pandas2.3.0，SQLAlchemy2.0.30，openpyxl3.1.2。

```powershell
pip install -r requirements.txt -r requirements-dev.txt
pip install -e .
python -m spear_shield
# 或安装后的命令
spear-shield
```

VS Code中选择本项目的Python解释器，F5选择“Spear & Shield 桌面应用”。不要直接运行具有相对导入的main.py文件。

默认数据与配置独立保存于 `%LOCALAPPDATA%/SpearShield/`，包括spear_shield.db、desktop.ini、logs/、backups/。
支持 `python -m spear_shield --data-dir D:/spear-shield/cache/my-local-data` 指定独立目录。
`--smoke-test` 启动真实事件循环后自动退出，仅用于验证启动，不运行回测或交易。

## 数据管理

1. 选择核心标的、前复权qfq或原始none、起止日期、供应商，点击“更新所选”。
2. ETF使用AkShare；399006指数可选择Sina备援。H30269接口不可用时明确失败，不替换标的。
3. 抓取运行于独立QProcess，45秒超时可杀掉进程；可手动取消，关窗口也终止抓取。结果完整返回且校验通过才落库。
4. 错误记录到更新日志及应用日志，旧缓存保留。行情日期与缓存写入时间是不同概念，缓存不是实时订阅。
5. 可勾选15/30/60分钟定时更新所选标的；每次启动默认关闭，已有任务运行时不会重复启动。供应商不一定以此频率发布新数据。
6. CSV/Excel必需列：date,open,high,low,close,volume；amount可缺失。日期必须是无时区的交易日日期。
7. 导入由使用者选择标的与复权口径，文件来源仅标记import:文件名，不认证为官方行情。先预检，再确认覆盖，同步备份数据库。
8. 单次导入最多20MB/100000行。重复日期、非法OHLC、非有限值、负量拒绝，缺失不填补。
9. CSV/Excel导出包含来源、复权与更新时间；文本型公式前缀被转义。备份通过SQLite backup API生成，不复制正在写入的文件。
10. 备份当前只增不自动删除；请自行管理备份存储空间。完整缺失交易日检查还需交易日历，界面不会伪装成已检查通过。

## 行情、周期与五维

- 行情页支持日/周/月、K线、MA10/60、BOLL上下轨，以及MACD、RSI14、ATR14、成交量。最近180根可框选缩放，重置按钮恢复视图。
- 波动为所选周期样本收益标准差、未年化；最大回撤为已知收盘样本峰值回撤；区间涨跌不是策略回测收益。
- 周/月按已有缓存聚合，末根可能未完结，交易日覆盖未确认；图和斜率卡片明确标注观察用途。
- 正式共振与五维状态来自Phase 4审计。缺IV/股债、序列/窗口待确认时不形成完整判断。可选择维度查看公式、来源、时间与已有审计趋势。
- 正式策略输入仍须满足发布时间、最终bar、时点复权及负责人定义确认，不能把当前qfq缓存直接包装为历史无前视数据。

## 信号与模拟账户

- 信号页选择审计记录，点击行查看条件表达式、输入证据、可用时间、确认记录、动作与规则版本。
- “运行可用性诊断”只保存明确的空仓研究诊断，行情证据为空，周线未确认；不是账户建议，也不会执行订单。
- 模拟账户只允许初始化一次，防止覆盖资金历史。用手工模拟价、份额与费用记账；支持四只核心ETF，不支持个股/卖空/透支。
- 金额使用整数万分之一元存储，买入费用计成本；卖出按加权平均成本分摊，显示已实现盈亏。
- 估值只用原始缓存价。缺原始价格时总权益/总盈亏/配置图不计算，不拿qfq价或0代替。持仓显示行情日期，估值不是实时。
- 实际配置图与防守端建议图分别展示；防守熔断未分配部分明确标注。建议缺失时留空。
- 当前模拟仅为手工研究记账，不校验交易所申报单位、T+1、分红或真实撮合；不连接券商。

## 回测与周报

- 回测页现支持真实缓存基准研究、费用/滑点、全区间净值/仓位、交易记录与JSON/HTML/CSV报告ZIP。完整策略仍明确阻塞，不计算虚假绩效；详见[回测手册](backtesting.md)。
- 周报选择截至日期，生成该自然周截至该日的缓存概况、五维变化、周期、审计信号、防守建议、风险与下周观察。
- 变化对比上周最后一条可用审计；本周没有审计/数据则明确缺失。只读当前加载的最近100条审计，不冒充全量绩效统计。
- PDF为可打印报告；Excel含市场观察、策略与风险、五维变化、信号记录、防守建议五个工作表。
