## 二、分层架构

```
┌─────────────────────────────────────────────────────────┐
│  UI 层（ui/）  PySide6 深色终端                              │
│  Dashboard · 温度计 · 共振 · 信号中心 · 资产 · 回测 · 账户 · 数据 · 周报 │
├─────────────────────────────────────────────────────────┤
│  服务层（services/）  定时更新 · SOP周报生成 · 任务队列（QThread）   │
├─────────────────────────────────────────────────────────┤
│  策略层（strategy/）  五维温度计 · 双周期共振 · 四档建仓 · P0-P3 · 防守 · 仓位 │
│        → 每条信号携带「触发依据/计算过程/优先级」用于解释               │
├─────────────────────────────────────────────────────────┤
│  指标层（indicators/）  60月线斜率 · 60周线斜率 · Z-Score · 股债性价比 · │

├─────────────────────────────────────────────────────────┤
│  回测层（backtest/）  回测引擎 · 交易成本 · 基准对比 · 防未来数据泄露      │
│  组合层（portfolio/）  模拟账户 · 持仓 · 成本 · 盈亏                    │
├─────────────────────────────────────────────────────────┤
│  数据层（data/）  DataProvider 抽象 → AkShare/Sina/Tushare 实现 ·       │

│  数据库层（database/）  SQLAlchemy ORM · SQLite · 备份                  │
├─────────────────────────────────────────────────────────┤
│  公共（config/ core/ utils/）  配置 · 日志 · 交易日历 · 常量             │
└─────────────────────────────────────────────────────────┘
```

### 核心设计决策

1. **数据源抽象为独立接口**（`DataProvider` 协议）：
   - `get_daily(symbol, start, end, adjust)`、`get_index_daily`、`get_margin`、`get_valuation` 等。
   - 策略层只依赖接口，不 import 具体供应商。
   - `DataProviderRegistry` 按优先级路由，失败自动降级到备援源。

2. **指标与策略彻底分离**：
   - `indicators/` 每个指标一个纯函数（输入 DataFrame → 输出数值/序列），无副作用，便于单元测试与追溯。
   - `strategy/` 只做规则组合与裁决，输出结构化 `Signal` 对象（含触发条件、计算过程、优先级、时间戳）。

3. **信号生成与模拟执行分离**（防未来数据泄露）：
   - 信号：基于周线收盘（周五后）数据生成。
   - 执行：回测用「下一交易日开盘价」模拟成交，绝不用当周收盘价。

4. **不可得指标显式降级**：
   - 期权 IV 等当前不可得维度返回 `NOT_AVAILABLE` 状态，不参与信号判定；UI 显示「不可计算」。

5. **GUI 不阻塞**：所有网络/计算放后台线程（QThread/QtConcurrent），前端仅消费结果。

6. **数据可追溯**：所有落库数据带 `source`、`updated_at`、`adjust_type`；原始（不复权）价格与复权因子并存。

## 三、数据模型（SQLite 核心表草案）

| 表 | 用途 |
|----|------|
| `market_daily` | 标的日线 OHLCV（前复权 + 原始 + 复权因子） |
| `market_index_daily` | 指数日线（399006、H30269、沪深300等） |
| `margin_daily` | 两融账户统计（日频） |
| `valuation_daily` | 指数 PE/PB/股息率 |
| `indicator_snapshot` | 每周五指标快照（五维 + 斜率 + ATR 等） |
| `signal_log` | 历史信号记录（含触发依据 JSON） |
| `account` / `position` / `order` | 模拟账户、持仓、成交记录 |
| `data_quality_log` | 数据缺失/异常/延迟记录 |

## 四、关键横切关注点

- **日志**：`logging` + 文件轮转，异常必记录。
- **配置**：用户配置与程序配置分离，独立 `config/`（如 `~/.spear_shield/` 或程序目录 config）。
- **数据库备份**：SQLite 定期备份（copy/export）。
- **敏感信息**：Token/密钥走环境变量或独立配置文件，绝不入库、不入 git。
- **测试分层**：`tests/unit`（指标/规则纯函数）、`tests/integration`（数据源/DB）、`tests/strategy`（策略边界与无未来函数验证）。
