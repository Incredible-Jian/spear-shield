### 关键观察
- **东方财富（push2）接口存在限流**：连续请求会触发 `Push2RateLimitError` 与 `ReadTimeout`。数据引擎必须实现：**限流退避、重试、本地缓存、失败不静默**。
- **sina 源可作为指数日线备援**，且全历史可用。
- **免费数据更新频率**：日频数据通常 T+1 收盘后可取；两融数据同样有延迟，须与原始发布频率一致并显示更新时间。

## 三、数据源架构原则

1. **抽象数据接口**：核心策略不依赖任何单一供应商。定义 `DataProvider` 抽象基类，实现 `AkShareProvider`（当前主源）、`SinaProvider`（指数备援）、`TushareProvider`（可选，需 Token）。
2. **本地 SQLite 缓存**：所有行情落库，命中缓存不重复请求，避免限流。
3. **数据质量检查**：缺失/异常/停牌标记，绝不静默填充；缺失时显示「数据不可用」而非伪造。
4. **数据更新时间与来源透出**：每个数据点携带 `source` 与 `updated_at`。
5. **前复权统一口径**：策略计算统一使用前复权；原始（不复权）价格仅存档，便于追溯复权因子。
6. **网络请求不进 GUI 线程**：后台线程/任务队列执行，避免界面卡死。
7. **不可得指标降级策略**：期权 IV 等当前不可得的维度，状态明确显示「不可计算 / 待接入」，不参与任何信号判定（即不把缺失当正常/当触发）。

## 四、风险与缓解

| 风险 | 影响 | 缓解 |
|------|------|------|
| 东财接口限流/变更 | 行情更新失败 | 多源冗余 + 重试退避 + 缓存 + 失败告警 |
| 免费接口不稳定 | 周报/回测数据缺失 | 本地缓存 + 历史导入 CSV/Excel |
| 期权 IV 无法免费获取 | 五维之一缺位 | 抽象接口 + 「不可计算」状态 + 待 Tushare/付费接入 |
| 复权因子口径差异 | 指标偏差 | 统一前复权，存档原始价与复权因子，可追溯 |
